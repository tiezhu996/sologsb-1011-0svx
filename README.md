# LiveCaption Desk · 实时字幕纠错台

LiveCaption Desk 是面向直播字幕校对员的长时间值守工作台。字幕按时间顺序进入待确认区，确认后进入直播区；校对员可以快速处理标点、专有名词、发言人和数字，并在弱网或断线时继续工作。

## 功能

- 实时待确认队列：按时间和序号显示字幕，支持只看需处理内容或异常优先。
- 字幕编辑：修改发言人、正文、标点和数字；支持全角数字、中文数字及常见数字格式规范化。
- 术语快捷替换：规则可限定发言人，可一键应用到当前字幕，并记录使用次数。
- 术语包版本对账：直播中途可整包导入带版本号的术语包（JSON），包只提供规则事实；同版本规则冲突先列出并整包拒绝，导入失败留下检查点，重试按版本+摘要幂等、不重复应用。
- 确认即锁版本：每段确认时记录生效术语版本，规则快照随包存档，已播字幕和回放不会被新规则悄悄改写。
- 人工修改保护：确认前/确认后的人工改动都会标记 `manualEdited`，重新检查时不会丢失，由校对员逐条决定是否升级。
- 版本对账面板：新版术语包到达后，重新检查只生成升级建议（纯规则可批量采纳，人工段单独确认），导出 SRT 与回放各按自己的确认版本取字幕。
- 直播确认：使用 `⌘/Ctrl + Enter` 确认后进入直播时间线，支持导出 SRT。
- 离线校正：断线后仍可继续修改和确认，确认内容进入离线发件箱。
- 顺序合并：恢复连接后按序号和开始时间排序合并，并重新检查重复和过期内容。
- 异常提示：重复片段、等待超过 90 秒的过期片段、最长等待时间和队列积压都会明确展示。
- 长时使用：提供深色值守界面、14–28px 字幕字号调整和清晰的键盘焦点。
- 键盘操作：`Alt + J/K` 切换片段，`⌘/Ctrl + 1–4` 插入常用标点，`⌘/Ctrl + Z` 撤销，`⇧⌘/Ctrl + Z` 重做。
- 本地持久化：所有修改、术语规则、连接模拟状态和界面字号保存在 `localStorage`。

- Lit 3

## 开发

```bash
npm install
npm run dev
```

开发服务器默认监听 Vite 的 `5173` 端口。模拟队列每 5 秒自动更新，可用界面中的“模拟断线”和“恢复并合并”演示离线流程。

## 术语包与版本对账

术语包是只包含规则事实的 JSON，整包原子导入（要么全应用、要么不应用）：

```json
{
  "version": "v2",
  "releasedAt": 1730000000000,
  "note": "直播中途下发",
  "rules": [
    { "id": "term-1", "source": "co pilot", "replacement": "CoPilot", "caseSensitive": false },
    { "source": "字幕稳定", "replacement": "字幕稳定性", "speaker": "" }
  ]
}
```

对账规则：

- 每段字幕在确认时锁定当时的 `activeVersion`，并保存该包规则快照；之后新包到达只更新规则账本，不改写已播字幕。
- 同一版本内或与已应用同版本包之间，出现「同原文 + 不同替换」时整包拒绝，冲突逐条列出，并写入导入检查点（失败原因、冲突、尝试次数）。
- 检查点支持「原样重试」（仍冲突则继续失败，绝不半应用）与「载入并修正」；同一个包（版本+内容摘要）重复导入会直接跳过，不重复应用。
- 「对账」标签对已播段重新检查：纯规则差异可一键批量采纳；含人工修改的段落单独标记、逐条确认，人工文本在升级中保留。
- 导出 SRT 与回放时间线都读取每段锁定版本的 `corrected`，各段按各的确认版本取词，不会被悄悄改写。

界面中提供两个演示按钮：「下发 v2」产生正常的中途术语升级，「冲突包」演示同版本冲突、整包拒绝与检查点重试。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。类型检查由构建命令自动执行。

## Docker

```bash
docker build -t sologsb-1011 .
docker run --rm -p 10011:80 sologsb-1011
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10011`。
