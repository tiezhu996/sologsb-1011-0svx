# LiveCaption Desk · 实时字幕纠错台

LiveCaption Desk 是面向直播字幕校对员的长时间值守工作台。字幕按时间顺序进入待确认区，确认后进入直播区；校对员可以快速处理标点、专有名词、发言人和数字，并在弱网或断线时继续工作。

## 功能

- 实时待确认队列：按时间和序号显示字幕，支持只看需处理内容或异常优先。
- 字幕编辑：修改发言人、正文、标点和数字；支持全角数字、中文数字及常见数字格式规范化。
- 术语快捷替换：规则可限定发言人，可一键应用到当前字幕，并记录使用次数。
- 直播确认：使用 `⌘/Ctrl + Enter` 确认后进入直播时间线，支持导出 SRT。
- 离线校正：断线后仍可继续修改和确认，确认内容进入离线发件箱。
- 顺序合并：恢复连接后按序号和开始时间排序合并，并重新检查重复和过期内容。
- 异常提示：重复片段、等待超过 90 秒的过期片段、最长等待时间和队列积压都会明确展示。
- 长时使用：提供深色值守界面、14–28px 字幕字号调整和清晰的键盘焦点。
- 键盘操作：`Alt + J/K` 切换片段，`⌘/Ctrl + 1–4` 插入常用标点，`⌘/Ctrl + Z` 撤销，`⇧⌘/Ctrl + Z` 重做。
- 本地持久化：所有修改、术语规则、术语包、导入检查点、连接模拟状态和界面字号保存在 `localStorage`。
- 术语版本对账：直播中途可导入带版本号的术语包，规则事实与字幕分离管理。
  - **整包原子导入**：术语包只提供规则事实；同版本内的规则冲突（同源不同替换、替换循环、结构错误）会先全部列出，任一冲突即整包失败，规则一条都不应用。
  - **失败检查点**：导入失败保留检查点（原始包、冲突清单、尝试次数）；可原样重试或修复后重试，同一版本幂等、不会重复应用。
  - **确认即锁版本**：每段字幕在确认时记录术语版本快照（原始文本、人工底稿、版本自动结果、是否含人工修改）。新版本术语包下发后，已播字幕和回放不会被悄悄改写。
  - **重新对账**：按「确认版本 → 目标版本」逐段生成建议；无人工修改的段给出干净升级，有人工修改的段走字符级三方合并，只合入不重叠的规则更新，改动重叠时标为冲突并保留人工播出文本，由校对员裁决后才记录对账结论。
  - **按确认版本取字幕**：直播时间线、播出版 SRT 导出按每段自己锁定的版本输出；也可选择某一术语版本做回放预览和回放版导出，冲突段回退为人工文本并明确提示。
  - 本机快捷规则作为叠加层与术语包规则共同生效，可增删；术语包规则只读，使用计数等事实不被对账改动。

## 技术栈

- Lit 3
- TypeScript 5
- Carbon Web Components 2
- Carbon Styles
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认监听 Vite 的 `5173` 端口。模拟队列每 5 秒自动更新，可用界面中的“模拟断线”和“恢复并合并”演示离线流程。第三栏“版本对账与直播区”提供两个演示术语包：`v2.0.0`（直播中途的干净升级）与 `v3.0.0`（含同版本规则冲突与替换循环，导入会失败并留下检查点，修复后可重试）。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。类型检查由构建命令自动执行。

## Docker

```bash
docker build -t sologsb-1011 .
docker run --rm -p 10011:80 sologsb-1011
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10011`。
